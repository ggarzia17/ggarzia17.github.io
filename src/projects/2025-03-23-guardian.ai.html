Guardian.ai - Blasterhacks 2025 Winner

March 2025

Guardian.ai is an emergency notification assistant that generates custom action plans for users based on their unique needs. It allows the user to create a bio that can include any information that would be needed in case of an emergency. Then Guardian.ai listens to multiple government hosted natural disaster APIs and analyzes the disaster to determine if it is a threat to the user. If Guardian.ai detects a threat it will then use the users bio to generate a custom action plan that takes into account any information they included in their bio. Guardian.ai will then notify the user via text and email that their is a potential disaster nearby and send them the action plan.

The LLM model we used was Llama 3-70b, which was hosted by Groq on their Language Processing Unit (LPU) AI inference technology. We utilized the increased speed to implement realtime feedback when the user was creating a bio. The LLM would notify the user about any information that could potentially be useful that they had not already added to their bio.

The frontend was created using Svelte and Tailwind. The backend was created using FastAPI and SQLite and was hosted on Docker. I worked with Brady Ancell and Matias Pena to build Guardian.ai
