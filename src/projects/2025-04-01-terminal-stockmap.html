Terminal Stock Map

April 2025

This is a terminal interface for the S&P500 stock map. It is written in Python with the yfinance API and Go with the bubbletea library.

The backend gathers the necessary data for the frontend by scraping Wikipedia's list of S&P500 companies and then querying the yfinance API to get price and market capitalization data. This data is then packaged into a json file to be read in by the frontend. Eventually this would be hosted on a server where it would run on a cron job.

The frontend parses the json file from the backend and sorts the data by sector and then industry. Next the frontend runs the algorithm to fit the stocks into the space they need. The size of each stock/industry/sector is weighted by its market cap. Because the terminal is relatively low resolution you can zoom in to a given sector and then industry to make them take up the full screen.
